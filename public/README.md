# public/ —— 前端静态资源

浏览器能直接访问的文件都在这里。

| 文件/目录 | 说明 |
| --- | --- |
| `game.html` | 游戏主页面：顶栏 / 资源条 / 三块界面（迷宫、阁楼、夜战）/ 流水 |
| `game.css` | 游戏主题样式：宋代志怪/宣纸/墨色/朱红；三屏显隐靠 `body.phase-*` |
| `game.js` | 入口模块，只做一件事：`import { start } from './js/main.js'; start();` |
| `js/` | 前端源码模块 |
| `js/store.js` | 单一状态源（局面 + 纯界面态） |
| `js/dom.js` | DOM 引用集中地，所有 getElementById 只出现一次 |
| `js/net/` | 网络：REST、SSE |
| `js/ui/` | 渲染组件（见下表） |
| `js/main.js` | 组装：事件绑定 + 启动序列 |
| `img/` | 妖物立绘（五张水墨图按属性共用）、印章等 |
| `CHANGELOG.md` | 版本更新日志（右上角版本号点开就是它） |

## 三屏与阶段

v4 把界面按局面阶段切成三块，`ui/render.js` 是唯一的切换开关：

| 阶段 | 面板 | 渲染器 | 干什么 |
| --- | --- | --- | --- |
| `maze` | `.maze-panel` | `ui/maze.js` | 走格、揭雾、房间结算、下潜、回阁 |
| `hall` | `.hall-panel` | `ui/hall.js` | 营造、货仓、精怪、日常、入夜 |
| `night` | `.night-panel` | `ui/guardian.js` | 献祭对打、咒术、架势、狂暴 |
| `over` | `.night-panel`（调暗） | — | 结算弹窗（`ui/modal.js`） |

面板显隐不用 JS 一个个切 `hidden`，而是把 `phase-*` 写到 `<body>` 上让 CSS 决定——
少一处状态就少一处漏网。

## `js/ui/` 组件一览

| 文件 | 职责 |
| --- | --- |
| `render.js` | 渲染调度：局面一变就按阶段调对应渲染器 |
| `survival.js` | 资源条（体力/饱食/精神/铜钱）+ 存活天数 + 这一局流水 |
| `maze.js` | 迷宫：格子、迷雾、方向键、脚下房间卡片 |
| `hall.js` | 万物阁：营造 / 货仓 / 精怪 / 日常四格 |
| `guardian.js` | 夜战：妖物立绘、血条、狂暴、连击 |
| `traveler.js` | 旅人面板：数值 / 装备 / 咒术 / 背景色调 |
| `stance.js` | 架势 / 限时 / 周目 / 遗物 / 道行 / 心得 |
| `offering.js` | 摄像头轮询、画框、祭品卡（同一个按钮在迷宫里是"递物"） |
| `act.js` | 一次夜战出手：读 ndjson 流、打击感演出 |
| `cast.js` | 念咒施法：语音识别 → 降级打字 |
| `hud.js` | 忙锁、回合指示、妖物攻击演出、看门狗 |
| `modal.js` | 权限闸门 / 更新日志 / 一局结算 |
| `session.js` | 一局的开始与结束、启动序列 |
| `fx.js` | 飘字、闪屏、抖动、角标、战报行 |
| `ambience.js` | 飘浮尘埃（纯装饰） |

## 前端分层

```
game.js → main.js → ui/*（渲染）
              ↓
          store.js（状态）
              ↓
          net/*（请求 / SSE 订阅）
```

前端不做任何规则计算：伤害、克制、饱食、铜钱、造价、境界全由后端算好
（`runSnapshot` 一次性给全，连"下一级设施多少钱"都是后端算的），前端只负责把结果画出来。
