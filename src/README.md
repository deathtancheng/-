# src/ —— 后端源码

这是《拾物奇谭》的后端主体，按功能分成四层：

| 目录 | 职责 |
| --- | --- |
| `config.js` | 唯一配置入口：端口、路径、Ollama、YOLO、摄像头地址 |
| `game/` | 游戏规则层（纯函数）+ 事件总线。前端_damage/克制/境界_全在这里算 |
| `harness/` | 自建的 Agent/Harness：ReAct 主循环、生命周期、扩展机制、工具注册 |
| `http/` | HTTP 服务：路由、静态资源、SSE、游戏/视觉/智能体接口 |
| `vision/` | YOLO 检测封装，调用摄像头常驻服务 |
| `agent/` | 本地大模型客户端相关辅助 |

启动入口是项目根目录的 `server.js`，它只负责组装：`createServer(ctx).listen(...)`。

## 核心设计

- **规则归代码，叙事归模型**：伤害、克制、架势、道行、境界……全部是纯函数；
  模型拿到的只有算好的数字，它只负责把它们写成故事。
- **前后端解耦**：后端算完通过 SSE 主动推局面；前端只订阅 + 渲染，不做任何规则计算。
