# src/game/ —— 游戏规则层

这里是《拾物奇谭》的全部"物理定律"。
v4.0 起游戏是「肉鸽 + 生存 + 策略 + 模拟经营」：白天在旧宅迷宫里拾物、
回万物阁经营，夜里妖物上门——天数就是你的成绩。

## 目录

| 文件 | 作用 |
| --- | --- |
| `bus.js` | 事件总线，后端算完局面通过它推给 SSE |
| `index.js` | 对外工具函数：`guardianFor(state)`（按 `beastId` + 天数缩放算出今夜妖物）等 |
| `rules/` | 规则纯函数：迷宫、房间、生存、设施、精怪、妖物、献祭、咒术、架势、道行…… |

## 设计原则

1. **纯函数优先**：同样的输入永远同样的输出（随机抖动除外），方便单元测试。
2. **状态可序列化**：`state` 是 plain object，直接 `JSON.stringify` 存盘。
3. **模型不碰数字**：所有数字在这里算好，模型只读结果写叙事。
4. **白天毫秒级**：迷宫与经营全是纯函数、不等模型；只有夜战的叙事才惊动模型——
   一格 13 秒的模型调用会把探索节奏拖死。
